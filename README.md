# -Java-Swing-Editor
A desktop Java IDE built with Java Swing that allows users to write, compile, and run Java programs directly from a graphical user interface.
)This project is a lightweight, standalone Java source code editor built using the Java Swing and AWT frameworks. Designed for quick coding and testing, it features a dual-pane graphical user interface that automates the compilation and execution processes of local Java files.
Key Features:-
* Auto-Boilerplate Generation: Automatically generates a standard public class template and main method structure as soon as you enter a class name and focus on the text editor.
* Integrated Compiler: Saves your code as a .java file and compiles it using the local JDK compiler (javac) with a single click.
* One-Click Execution: Runs the compiled .class bytecode via the Java Runtime Environment (java) directly from the GUI.
* Console Output Console: Displays real-time compilation success messages, execution logs, and runtime error outputs in a dedicated bottom text panel.
